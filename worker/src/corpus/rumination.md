# Rumination

<!-- keywords: overthinking, rumination, overpikir, mikir, loop, worry, khawatir, anxious, cemas, replay, nocturn -->

## The loop

Rumination is a question that keeps returning without moving toward an answer. It often feels
productive, like if you replay the conversation one more time you will finally find the missing
piece. The loop can keep going because it never reaches a stopping rule. Notice the question you are
asking. If it has no answer you could write down, it may be a loop rather than a problem to solve.

## Scheduled worry

Give the loop a time and a page instead of fighting it all day. Set aside ten minutes later today,
write the worry at the top, and list what is known, what is unknown, and one thing you can do. When
the time is over, close the page and return to the next task. The worry may come back; the point is
that it has a place to go, so it does not have to run in the background all day.

## Grounding

When the loop is loud, give your attention something concrete. Name five things you can see, four
you can hear, three you can touch, two you can smell, and one you can taste. Then make the exhale a
little longer than the inhale for a few breaths. This does not solve the problem. It brings you back
to the room so you can choose what to do next.
